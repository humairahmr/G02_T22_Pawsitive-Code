# Blackbox Studio Booking App

![CI](https://github.com/humairahmr/G02_T22_Pawsitive-Code/actions/workflows/ci.yml/badge.svg)

A Flutter app for Blackbox Studio, a photography studio in Bintulu, Sarawak. Customers sign up, browse packages and book a session. The studio owner manages bookings, customers and reviews. Built by Group 22 (Pawsitive Code) for TMA3084.

## Run

    flutter pub get
    flutter run -d chrome

## Test

    flutter test --coverage
